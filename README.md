# B8A1 - Problem Solving with TypeScript & OOP

## Overview

This is my solution for Assignment 1 of the TypeScript course. It covers basic types, optional, default and rest parameters, readonly tuples, interfaces, type narrowing, generics, Promises and object-oriented programming.

All 8 problems are solved in one file, [solutions.ts](https://github.com/shimul705/assignment1-b8-L2/blob/main/solutions.ts):

1. `multiplyValue` - optional parameter with a default multiplier of 2
2. `processInput` - union type and `typeof` narrowing
3. `formatCoordinate` - readonly tuple
4. `concatenateArrays` - generic function with rest parameters
5. `Course` and `getPopularCourses` - interface and filtering an array
6. `pluckValues` - generics with `keyof`
7. `Employee` and `Manager` - classes, inheritance and access modifiers
8. `validateAgeAsync` - async function that returns `Promise<string>`
